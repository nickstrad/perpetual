# Durable request diagram sources

These Mermaid sources generate the walkthroughs in [the slice overview](../README.md)
and [architecture](../architecture.md). The architecture also uses the
[shared decision loop](../../diagrams/architecture-decision-loop.mmd).
Keep the generated text with its source; do not edit rendered blocks by hand.

Follow the [rendering instructions](../../diagrams/README.md), running the commands
from `docs/plans/durable_requests/` for this slice. `--check *.md` checks both
Markdown documents with generated diagrams; `plan.md` contains design sketches.
